# Exemplo: telemedicina rural / Example: rural telemedicine

**PT.** Três entrevistas fictícias para você testar a Skill do Synesis no Claude Desktop.

- `fontes/`: as entrevistas (`.txt`). Copie esta pasta para uma pasta nova, abra-a na aba Code do Claude Desktop e digite:
  `/synesis Quero codificar minhas três entrevistas sobre telemedicina. As transcrições estão em fontes.`
- `resultado/`: o que a Skill gerou numa sessão real com estas mesmas entrevistas: projeto (`.synp`), template (`.synt`), anotações, ontologia e três páginas, que abrem com dois cliques: a visão do projeto (`view/index.html`), a conferência de uma amostra das anotações (`review/index.html`) e os resultados (`dashboard/dashboard.html`). Use para comparar com o seu.

A codificação é feita por um modelo de IA; o seu resultado será parecido, não idêntico. Compare a estrutura e os critérios, não cada palavra.

**EN.** Three fictitious interviews to try the Synesis Skill in Claude Desktop.

- `fontes/`: the interviews (`.txt`). Copy this folder into a new folder, open it in the Code tab and type:
  `/synesis I want to code my three interviews about telemedicine. The transcripts are in fontes.`
- `resultado/`: what the Skill produced in a real session with these same interviews: project (`.synp`), template (`.synt`), annotations, ontology and three pages, which open with a double click: the project view (`view_en/index.html`), the review of a sample of the annotations (`review_en/index.html`) and the results (`dashboard/dashboard.html`). Use it to compare with yours.

The coding is done by an AI model; your result will be similar, not identical. Compare structure and criteria, not every word.

Todas as pessoas e falas são fictícias. / All people and statements are fictitious.
