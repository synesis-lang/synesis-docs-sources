Which format is right for my material?

References with abstracts (.bib)

Choose it when
you review literature and the abstract is enough to answer your questions; good for dozens or hundreds of articles.
What is coded
only the abstract of each reference, never the full article.
What it needs
a .bib file exported from Zotero, Mendeley, Scopus or Web of Science, with the abstract field filled in.
Example
@article{silva2024,
  author   = {Silva, Ana},
  title    = {…},
  year     = {2024},
  abstract = {…}
}

Texts (.txt or .md)

Choose it when
you have interviews, field notes, documents, or articles whose full text matters.
What is coded
the whole text, split into parts when it is long.
What it needs
one file per source. Word files (.docx) are converted. Each text also needs a reference entry: the intake creates it.
Example
fontes/
  ent01.txt
  ent02.txt
  diario_campo.md

Records (.toml)

Choose it when
each source has the same structure: forms, open survey answers, posts, news with date and outlet, curricula.
What is coded
the sections the template points to; fixed data such as date or outlet is copied from the record, not interpreted.
What it needs
one file per record, with the same sections and a unique identifier. The template must be designed for it; plan it with Claude.
Example
[story]
id     = "n001"
date   = "2024-05-10"
outlet = "…"

[text]
body = """…"""

Do you have PDF files?

Convert them to .txt before adding them. Conversion needs your eyes: columns, headers and scans go wrong silently.

  1. Open the PDF and try to select a sentence. If you cannot, it is a scanned image: it needs text recognition (OCR) first.
  2. Open it in Word (it converts the PDF), or select all the text and paste it into a text editor.
  3. Save as plain text (.txt) with UTF-8 encoding, one file per document.
  4. Read the result: columns in the right order, no headers, footers or page numbers in the middle of sentences, no words broken by hyphens, accents correct.

Many PDFs? A connector such as PDF Tools (claude.com/marketplace/connectors/pdf-tools) can convert text PDFs; ask Claude. Its output passes through Claude, so use it only if your confidentiality choice allows Claude to read the sources. It does not recognize scanned pages by itself, and you still have to check the result.

If the article has a reference with an abstract, the .bib may be enough, with no conversion.

Start from what you want to investigate, not from the name of a field. Each possibility shows a need, an example, the decision it asks for and the Synesis feature that carries it out. The request can be copied and adapted in the conversation with Claude: Claude will clarify your intention and present alternatives before proposing a structure.

Goal: you can say “I want to investigate this; help me record and analyze it”, even without knowing the names of the fields.

I want to compare

Comparing sources, excerpts or groups needs a common criterion, recorded the same way everywhere.

“I need to record intensity, degree or an assessment as a number.”

Example
How much trust a person expresses in an institution, from 1 (none) to 5 (full).
Synesis feature
SCALE GUIDELINES
In this project
This project has no scale yet. A possibility to consider: grading how strongly each excerpt shows «consulta_por_video» or «confianca_no_atendimento».
Methodological decision and request to Claude
Decision to make

Do you want to record the rating given by the source itself, or rate yourself the intensity described in the excerpt? They are different pieces of information and may need separate fields. Either way, each level needs a written criterion, so that the same situation always gets the same number.

Request to adapt

I want to record an intensity or a degree in the annotations of project telemedicina_rural, for example how strongly each excerpt shows «consulta_por_video». Before proposing anything, ask me up to three questions to understand my intention, including whether the number comes from the source or from me. Then present alternatives and propose the levels of the scale, a criterion for each level and an example from the project. Do not change any file before I approve.

“I need to sort sources or excerpts into fixed categories, to compare groups.”

Example
Kind of participant (leader, volunteer, neighbor) or stage of the group (start, consolidation, decline).
Synesis feature
ENUMERATED ORDERED
In this project
The sources in this project are described by «descricao», in free text. To compare sources by category, such as the kind of source, a closed-list field at the source level would help.
Methodological decision and request to Claude
Decision to make

Do the categories have an order (low, medium, high) or are they just different? With an order, use ORDERED; without, ENUMERATED. And does the category describe the whole source or each excerpt?

Request to adapt

I want to compare groups of sources or excerpts in project telemedicina_rural. First ask me which groups I want to compare and whether the categories have an order. Then present alternatives and propose a field with the categories, the definition of each and the level where it is filled in (the whole source or each excerpt). Do not change any file before I approve.

I want to connect

Links between concepts show mechanisms: what leads to what, what enables or prevents what.

“I need to represent how the sources connect concepts or other information.”

Example
infrastructure → ENABLES → change of habit
Synesis feature
CHAIN RELATIONS
In this project
This project already has the field «cadeia», with 6 chains recorded. For example:
sinal_de_celular→RESTRINGE→consulta_por_video
Methodological decision and request to Claude
Decision to make

The chain records the connection; the relations (RELATIONS) define the meaning of each allowed connection. Use the chain when the source supports the link. If the connection is your own hypothesis, agree with Claude on a way to record it as interpretation, for example in the memo.

Request to adapt

I want to represent how the sources of project telemedicina_rural connect concepts, for example «consulta_por_video» and «confianca_no_atendimento». First ask me which kind of connection interests me and how to tell a connection stated by the source from one that is my interpretation. Then present alternatives and propose the field, the relations and guidelines with right and wrong examples. Do not change any file before I approve.

“I need to tell apart the different ways things relate.”

Example
CAUSE (one factor produces another), CONDITION (one factor makes another possible), RESTRICTION (one factor hinders another).
Synesis feature
RELATIONS
In this project
Declared relations and how often they were used: CAUSA (1), HABILITA (2), RESTRINGE (3).
Methodological decision and request to Claude
Decision to make

A few well-defined relations compare better than many similar ones. Each relation needs a definition, an example and a situation where it does not apply.

Request to adapt

Help me review the relations of project telemedicina_rural. First ask me which distinctions matter for my research questions. Then propose, for each relation, a definition, an example and a situation where it should not be used. Do not change any file before I approve.

I want to understand and organize

Well-defined concepts gather passages about the same phenomenon and make the analysis reviewable.

“I need to gather passages about the same phenomenon.”

Example
Every excerpt that talks about dropping out gets the same concept, whose definition says when to apply it.
Synesis feature
CODE ONTOLOGY
In this project
11 concepts defined in the ontology; 3 appear in a single source.
Methodological decision and request to Claude
Decision to make

Reuse an existing concept or create a new one? A new concept needs a definition, with a criterion for when to apply it and when not to.

Request to adapt

Help me propose concepts for the excerpts of project telemedicina_rural, telling apart those already in the ontology from those that need a new definition. For each new concept, propose the definition, when to apply it and when not to. Do not change any file before I approve.

“I need to group concepts into broader themes.”

Example
Lack of water, insecure land and lack of funds gathered under the theme «obstacles».
Synesis feature
TOPIC
In this project
The concepts are grouped in 10 themes: beneficio_percebido (1), conectividade (1), cultura_e_vinculo (1), custo_de_acesso (1), facilitadores (1), habilidades_do_usuario (1), infraestrutura (2), pratica_clinica (1), preferencia_de_atendimento (1), telemedicina (1).
Methodological decision and request to Claude
Decision to make

A theme gathers concepts but does not replace the definition of each one. Prefer a few themes that help read the whole.

Request to adapt

Help me review how the concepts of project telemedicina_rural are grouped into themes. First ask me what overall reading I want to make. Then propose the themes, the concepts in each and those left out. Do not change any file before I approve.

I want to support my interpretation

An interpretation convinces when one can go back to the source and see where it came from.

“I need to keep the words of the source and develop my interpretation.”

Example
The excerpt copied word for word and, next to it, a memo saying why it matters.
Synesis feature
QUOTATION MEMO
In this project
12 of 12 excerpts were located in the source.
Methodological decision and request to Claude
Decision to make

The excerpt is the evidence; the memo is your reading. Mixing them weakens the analysis. An excerpt not located in the source has to go back to it.

Request to adapt

I want to keep evidence and interpretation apart in the annotations of project telemedicina_rural. Check that the excerpts are literal copies of the source and that the memos bring interpretation, not paraphrase. Show the cases to fix. Do not change any file before I approve.

“I need to link each annotation to my research questions.”

Example
The memo ends with (Q1) when the excerpt helps answer the first question.
Synesis feature
QUESTIONS MEMO
In this project
0 of 12 memos cite a question (Q1, Q2, Q3).
Methodological decision and request to Claude
Decision to make

Citing the question in the memo shows what each excerpt is for and reveals questions with little evidence.

Request to adapt

I want to see how much evidence project telemedicina_rural gathers for each research question (Q1, Q2, Q3). Count the memos that cite each question and point out the questions with little evidence. Do not change any file before I approve.
