telemedicina_rural

Este é o projeto telemedicina_rural: 3 fontes, 12 itens e 11 conceitos. A página só mostra os arquivos; as mudanças são feitas nos arquivos ou pedindo ao Claude na conversa.

  1. Nada pendente: o projeto compila e todos os trechos foram localizados nas fontes.
  2. Para explorar, use a matriz Conceitos por fonte: clique num conceito para vê-lo em foco e numa célula para ler os trechos daquela fonte. O conceito mais frequente é «consulta_por_video» (6 itens).
  3. As palavras em azul nos arquivos (como SCOPE e END ITEM) explicam-se ao passar o mouse. A aba Possibilidades de pesquisa sugere o que mais registrar, com pedidos prontos para o Claude.

Visão somente de leitura dos arquivos Synesis. Edite os arquivos, não esta página. Passe o mouse sobre as palavras em azul, os nomes de campo, os conceitos e as relações: uma explicação curta aparece.

Suas fontes

Coloque as suas fontes

Ponha os arquivos que você tem numa pasta só, do jeito que estão. O programa auxiliar do Claude os examina no seu computador, diz o que é cada um e como pode ser usado, e prepara o que você aprovar. Os originais nunca são alterados.

  1. Copie os seus arquivos para a pasta entrada/, dentro do projeto.
  2. Avise o Claude (o botão copia o pedido).
  3. Leia o inventário e a recomendação para cada arquivo.
  4. Decida. Só então os arquivos são preparados para a codificação.

Antes de copiar entrevistas, retire nomes e outros dados que identifiquem pessoas, no texto e nos nomes dos arquivos. O inventário é feito no seu computador; o que o Claude pode ler depende da escolha de confidencialidade feita no início.

Que formato serve para o meu material?

Referências com resumo (.bib)

Escolha quando
você revisa literatura e o resumo basta para responder às suas questões; bom para dezenas ou centenas de artigos.
O que é codificado
só o resumo (abstract) de cada referência, nunca o artigo inteiro.
O que precisa ter
um arquivo .bib exportado do Zotero, Mendeley, Scopus ou Web of Science, com o campo abstract preenchido.
Exemplo
@article{silva2024,
  author   = {Silva, Ana},
  title    = {…},
  year     = {2024},
  abstract = {…}
}

Textos (.txt ou .md)

Escolha quando
você tem entrevistas, diários de campo, documentos ou artigos em que o texto completo importa.
O que é codificado
o texto inteiro, dividido em partes quando é longo.
O que precisa ter
um arquivo por fonte. Arquivos do Word (.docx) são convertidos. Cada texto também precisa de uma referência: o recebimento a cria.
Exemplo
fontes/
  ent01.txt
  ent02.txt
  diario_campo.md

Registros (.toml)

Escolha quando
todas as fontes têm a mesma estrutura: formulários, respostas abertas de questionário, posts, notícias com data e veículo, currículos.
O que é codificado
as seções que o template indica; dados fixos, como data ou veículo, são copiados do registro, sem interpretação.
O que precisa ter
um arquivo por registro, com as mesmas seções e um identificador único. O template precisa ser desenhado para isso; planeje com o Claude.
Exemplo
[story]
id     = "n001"
date   = "2024-05-10"
outlet = "…"

[text]
body = """…"""

Você tem arquivos PDF?

Converta-os para .txt antes de colocá-los na pasta. A conversão precisa dos seus olhos: colunas, cabeçalhos e digitalizações dão errado em silêncio.

  1. Abra o PDF e tente selecionar uma frase. Se não conseguir, ele é uma imagem digitalizada: precisa antes de reconhecimento de texto (OCR).
  2. Abra-o no Word (ele converte o PDF), ou selecione todo o texto e cole num editor de texto.
  3. Salve como texto sem formatação (.txt), com codificação UTF-8, um arquivo por documento.
  4. Leia o resultado: colunas na ordem certa, sem cabeçalhos, rodapés ou números de página no meio das frases, sem palavras partidas por hífen, acentos corretos.

São muitos PDFs? Um conector como o PDF Tools (claude.com/marketplace/connectors/pdf-tools) pode converter os que têm texto; peça ao Claude. O resultado passa pelo Claude: use só se a sua escolha de confidencialidade permite que ele leia as fontes. Ele não reconhece sozinho páginas digitalizadas, e a conferência continua sendo sua.

Se o artigo tem uma referência com resumo, o .bib pode bastar, sem nenhuma conversão.
